## 🚀 Installation

Pour lancer le portfolio en local :

```bash
# Cloner le repo
git clone https://github.com/claradorable/portfolio.git
cd portfolio

# Lancer le serveur de développement Symfony
symfony server:start --port=8000 --dir=portfolio-app
```

Le site sera accessible sur `http://localhost:8000`
